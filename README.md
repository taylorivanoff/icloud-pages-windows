# iCloud Pages for Windows

iCloud Pages desktop app for Windows. Loads [https://www.icloud.com/pages](https://www.icloud.com/pages) in a native **Tauri / WebView2** shell.

## Development

Requires Rust (MSVC), WebView2, and Bun. Sibling crates:

- `Projects/tauri-tray-base`
- `Projects/tauri-icloud-base`

```bash
bun install
bun run icon
bun run dev
```
